# Research Notes

This folder stores source-specific research material for Case 02.

Use [Source Influence Register](source_influence_register.md) as the canonical
place to record which external sources influenced Case 02 and what was taken,
excluded, or parked. Do not duplicate the register in this README.

## Folder Rule

External material may inform Case 02, but it must not automatically rewrite the
README, scope, architecture, validation, provenance, or public claims.

Create a separate note in this folder only when a source needs more detail than
fits in the register. Keep durable project policy and architecture documents
source-agnostic.

## What Belongs Here

- compact source summaries;
- notes on why a source matters or does not matter;
- source-specific details that should not clutter durable Case 02 documents;
- parking notes for useful material that does not yet justify repo changes.

## What Does Not Belong Here

- copied full papers or transcripts;
- new project scope;
- README replacement text;
- source-specific framing for reusable Case 02 policies;
- claims that Case 02 cannot validate.
